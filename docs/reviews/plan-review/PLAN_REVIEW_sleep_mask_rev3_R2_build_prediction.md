## Invariant break attempts (the six questions asked)

| Probe | Result |
|---|---|
| Unavailable at restart, then back ON "without an edge" | **Holds.** unavailable→on is an `EVENT_STATE_CHANGED`. The seed and subscribe in `async_setup` have no await between them. An `on`→`on` event that only changes attributes doesn't change the OR, which is correct. The real boot hole is the reverse direction (on at seed, off during settle), **R2-4**. |
| Substrate vs tracker edge ordering | **Holds on the live path.** `_on_substrate_kind_changed` is `@callback` and the state listener is synchronous, so the tracker updates inside the substrate callback, in event order. **Breaks at the edges:** refresh failure (**R2-6**), deletion lifecycle ordering (**R2-3**), boot release (**R2-4**). |
| Fan-radar sleeper vs stuck-on: empty house held HOME | **Yes, when α is blocked**, as the plan states. With Frigate dark, the Jaya LD2410 + fan loop (fan-off acts only on house AWAY, state of play §9) holds HOME indefinitely, and D4d pages once a day after 2 h. Wigton: a phantom ZX in Master holds HOME forever with no page (α starved, D4d inert, `tracked_count == 0`). The plan names this gap. Recommend a card for "Wigton stuck-ZX page without a tracker denominator". INV-NO-EMPTY-HOUSE-HOLD-WHEN-ALPHA-LIVE itself holds: α (`presence.py:1192-1206`) reads no zone term. |
| Daytime: zone flaps, HVAC wait-for-presence, energy counts | Zone flaps go down (fewer dispatches). The energy counts are analytics only. **The HVAC D6 gate claim is wrong, R2-5.** |
| D1 after the live-limb deletion: is a sleeping single-radar room still held? | **Yes, with the constant True.** The tracker is edge-true while the radar reads `on`. INV-NIGHT-RAW-EQUALS-RAW checks out against `_derived_mode` (BLE → has_sensors → rooms incl. hold → camera). Unavailable counts as off, the same as the deleted limb. **With the constant False it is NOT held in multi-sensor rooms, R2-1.** |
| D4d false pages and latch | Per-episode flag plus the per-day `fire_stuck_signal` latch: at most one page a day; no re-fire storm. False-page sources: an outdoor-zone radar (Patio, 5.3 h, measured) while Frigate is dark. That page is arguably valid, since nobody-home reads outdoor zones too. See R2-10 for the scope wording. |
