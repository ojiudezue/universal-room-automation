## D2: HVAC Actuation Path (`_async_apply_preset_overrides`)

### Arrester suppress/unsuppress pairing

CORRECT. The pattern is: `suppress(entity)` before `async_call("set_temperature")`, NO unsuppress on success, `unsuppress(entity)` only on failure. This matches the established pattern throughout hvac.py (lines 688-705, 822-866). The OverrideArrester's `_handle_climate_change` (hvac_override.py line 510-512) auto-discards suppression on the next state-change event for that entity. No suppression leak risk.

### `set_temperature` payload shape

CORRECT. Lines 986-991: `target_temp_low` and `target_temp_high` both provided. This is the required format for HA's climate API when the entity is in `heat_cool` mode.

### Throttle correctness (`_last_emitted_range`)

- **HA restart:** `_last_emitted_range` initialized to `{}` in `__init__` (line 182). First post-restart cycle will re-emit all override ranges. CORRECT.
- **Entry reload:** Coordinator instance is destroyed and re-created. New instance has empty dict. Re-emits on first cycle. CORRECT.
- **Master toggle OFF->ON:** `async_turn_off` at line 957 calls `hvac._last_emitted_range.clear()`. Next enable re-applies from scratch. CORRECT.

### Observation mode gating (Bug Class #23)

CORRECT. The gate is at line 907: `if not self._observation_mode: await self._async_apply_preset_overrides()`. The gate is on the ACTUATION side (HVAC coordinator), not the SOURCE side (EC evaluation). EC still computes and stores overrides for sensor display during observation mode; HVAC just doesn't call `set_temperature`. This is the documented correct pattern per Bug #23.

### Cycle budget impact

`_async_apply_preset_overrides` runs once per `_apply_house_state_presets` call. For N canonical zones: N iterations of `get_active_overrides` (list filter) + `resolve_range` (sort + iterate) + 1 `async_call("set_temperature", blocking=False)` per changed zone. The `blocking=False` means the service call returns immediately. The OverrideEngine operations are O(overrides) where overrides is typically 1-4 per zone. With 3-5 zones and up to 5 overrides each, this adds negligible latency to the decision cycle.

### D2 verdict: PASS
