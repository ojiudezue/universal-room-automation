## Scope (bundle)

1. **#2 — dead compliance-rate sensors** (`sensor.py` PresenceComplianceSensor,
   SafetyComplianceSensor). `native_value` (sync property) called the async
   `get_compliance_rate` DAO without `await` → un-awaited coroutine → `rate*100`
   raised TypeError → swallowed → hardcoded `100.0` returned forever, plus a
   RuntimeWarning each poll. Fix: `native_value` returns cached
   `getattr(self, "_compliance_value", 100.0)`; new `async def async_update`
   awaits the rate and caches it (mirrors the `LastIdentifiedTime` sensor at
   `sensor.py:2516`).

2. **#3 — HVAC post-peak coast release** (`energy.py:_update_hvac_constraint`).
   The mid_peak HVAC coast now releases to `normal` in summer **post-peak**
   mid_peak (season=summer AND `not peak_ahead_before_offpeak()`), keeping coast
   in summer pre-peak and shoulder/winter. Mirror of the v4.7.29 battery fix.

3. **B-MED-1 fix-up** (`hvac.py:_handle_energy_constraint`) — see below.

## Proposed new QUALITY_CONTEXT bug class

**#52 — Async DAO called from a sync property/context without `await`.** An async
coroutine invoked from a synchronous `native_value`/property returns an
un-awaited coroutine; downstream arithmetic raises `TypeError`, a broad `except`
swallows it, and the entity silently reports a hardcoded fallback (plus a
per-poll `RuntimeWarning`). Symptom: a sensor pinned at a suspiciously round
constant. Guard: any DB/DAO read in an entity must happen in `async_update`
(cache the result); `native_value` returns the cache. (This cycle, #2.)
