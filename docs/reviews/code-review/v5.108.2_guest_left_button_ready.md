QUALITY_CONTEXT recommendation: when an unpolled entity (`ButtonEntity`, or any `_attr_should_poll=False`) gates `available` on a coordinator or `hass.data` lookup that is registered after platform setup, it MUST subscribe to that component's READY signal. The "buttons are never polled" rule already appears in the `_ACRampButton` docstring (v4.5.11.3), so this is a known recurrence. Consider recording it as a named bug class.
