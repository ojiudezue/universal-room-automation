## Recommendations for QUALITY_CONTEXT.md
- **Candidate new class: "stale async continuation".** A task scheduled for an episode (grace / compromise / revert) runs after a person or a newer episode superseded it. The pattern that fixed all three findings: a per-key MONOTONIC generation captured at scheduling time, re-checked after EVERY await that precedes a write or a timer arm, plus an identity-checked pop of the task's own timer handle.
- **Extend "suppression needs a discharge"** to protective latches. The discharge must ignore unavailable/unknown flaps (D-M1), and the latch must survive a restart through the existing zone-state store (D-M2).
