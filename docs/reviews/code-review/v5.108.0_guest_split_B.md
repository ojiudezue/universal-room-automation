## Cleared (holds because)

- **Night yield, no flap.** `infer()` checks the GUEST exit (`presence.py:1399`) before the sleep branch (`:1404`), and the sleep branch precedes guest entry (`:1425`). So HOME_NIGHT at a sleep hour always proposes SLEEP, never GUEST, even though `_compose_guest_gate` returns `stay` unmasked for HOME_* — no GUEST↔HOME_NIGHT oscillation. No new state-machine edge; §10 #29 still true.
- **Morning return.** SLEEP → WAKING (sustained gate) → HOME_DAY (dwell 120 s) → HOME_* branch composes `stay` → GUEST. Pinned by `test_morning_reentry`. The daily walk is scheduled at the first tick after the window end; a latch change then is a single edge with S9 persistence on exit.
- **Clock for the yield.** `now = dt_util.now()` (local) in `_run_inference`; `infer()` derives its own hour. A boundary-straddling tick can disagree for one tick: GUEST + armed at 22:00 → engine proposes SLEEP → rejected by `VALID_TRANSITIONS` (pre-existing benign shape).
- **Read/transition atomicity.** `_stay` is read once into a local (`presence.py:6900`); no `await` between it and `transition()`. The walk writes the latch only after its awaits and then runs one inference; `_run_inference` is unserialised but that is pre-existing (many `async_create_task` callers).
- **Restart / restore.** Latch is a pure function of DB rows (no Store); a restored GUEST with the walk still pending proposes an exit that S9 holds 300 s; the walk (2 reads per guest room on the read connection, not the write queue) lands well inside that. DB absent at setup → no walk scheduled, retried by `_guest_stay_tick`. `CancelledError` is not swallowed (`except Exception`).
- **Teardown.** Walk task cancelled in `async_teardown`; D4 NM uses `fire_stuck_signal` (module per-day dedup, so a restart re-pages at most once per day).
- **Kill switch byte-identical.** Rule OFF: `_compose_guest_gate` returns `room` at both sites; S4 reason and S5 canary guarded by `_stay_rule_on`; entry log guarded; `_maybe_schedule` returns False; `_check_guest_stay_long` sees latch False. New display surfaces (`visitors_present`, house-state `guest_stay_*` attrs) do not feed `infer()`. Golden `test_kill_switch_byte_identical` passes.
- **Consumers.** HVAC preset `guest → home` (same as HOME_DAY), legacy day tail through stay days, Custom Preset Ranges `house_state == "guest"` now active on stay days, arrester `guest` hold-preserving: all as plan §3.3; no HVAC code touched, no HVAC §10 claim re-asserted.
