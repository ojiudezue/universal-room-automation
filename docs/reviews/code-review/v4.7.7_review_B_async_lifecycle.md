## File-by-File Findings

### `domain_coordinators/hvac_override.py`

**B-LOW-1 — TOCTOU on `_ac_reset_enabled` between `check_ac_reset` and `_perform_hard_reset_escalation`** (Bug Class #20)
A2 split snapshots both flags at L891–L892 of `check_ac_reset`. But `_perform_hard_reset_escalation` (called ~10 minutes later via `async_call_later` → `_evaluate_nudge_outcome`) reads `self._ac_reset_enabled` LIVE at L1532. This is the EXPECTED semantic ("escalate based on current toggle, not the toggle at nudge-start time") but is worth a one-line comment clarifying the deliberate intent. Not a blocker.

**B-INFO-1 — A2 setter has no side effect on OFF (as designed)** Plan §A2 locked this; verified. Setter only assigns + logs. No timer cancellation.

### `__init__.py`

**B-LOW-3 — A4 collision check uses `_er.async_get(entity_id)`** Edge case if entity is removed mid-iteration; the `try/except Exception` block at L2598 catches defensively. Acceptable defense in depth.

### `sensor.py` + `energy.py` + `dynamic_preset.py`

**B-MEDIUM-1 — `skipped_zones_with_reason` updates not always visible**
`DynamicPresetOverridesAppliedSensor` subscribes only to `SIGNAL_DYNAMIC_PRESET_OVERRIDES_UPDATED` and `SIGNAL_DYNAMIC_PRESET_TRANSITIONED`. The EC dispatcher fires only when the overrides dict actually changed. When ONLY `skip_reason` changes between ticks (e.g., zone moves `gate_disabled` → `home_range_not_configured` while overrides stay `[]` both ticks), the sensor will NOT refresh.

**Action:** Either (a) accept as documented diagnostic-sensor staleness, or (b) fire a separate signal when `skip_reasons` change. (a) is acceptable for v4.7.7; defer (b) to v4.7.8 if user feedback indicates the staleness is confusing. The skip_reasons dict ASSIGNMENT IS atomic.

**B-INFO-3 — Bug Class #45 dict-comp keying** CORRECT. No stale-closure hazard.

**Cross-coordinator signal ordering — SAFE.** Deferred-restore failure mode is well-handled.

**Concurrent reload race for the new switch (Bug Class #20):** Same risk as the reference HVACACResetSwitch; no regression.
