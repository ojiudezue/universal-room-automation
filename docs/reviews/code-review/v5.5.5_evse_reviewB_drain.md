## Summary (<250 words)

The D2 solar-gate is **correct and well-bounded**. The reserve-gated guarantor
(`battery_out_of_capacity`, SOC ≤ reserve+2) is **byte-identical** to develop
(`energy_pool.py:1023-1033`, EV; `:1928-1937`, plug) — only `soc_recovered` gained
the `solar_replenishing and` prefix (`:1029`, `:1971`). The reserve guarantee is
untouched and remains the governing release at night.

The gate signal is correctly **time-anchored**, not solar-instantaneous.
`expected_solar_surplus_now_pct` (`energy_battery.py:1635-1651`) wraps the FIN-2
primitive `_expected_solar_surplus_pct` (`:1695`), which pro-rates `solcast_remaining`
by daylight-window overlap (`overlap_h / remaining_h`, `:1755`). At night the
today-branch is skipped (`now >= sunset_today`) and the tomorrow-branch slices to
`[tomorrow_sunrise, boundary]` → ~0 overlap → ~0%. Raw `solcast_remaining` (the banned
all-night-high bug signal) is **never** used for the phase decision. The `1.0%` floor
(`energy_const.py:570`) plus the `battery_power_w > +100W` live-charge OR-term
(`energy.py:2705`) is a reasonable, conservative judgment constant.

The "never discharge into EV" invariant holds day and night: pause stays
`charging AND battery<-100W AND soc<threshold` (`:992`); the genuine daytime-no-solar
discharge case is still protected. Pause ownership uses the dedicated
`_paused_by_battery_drain` set (no #15/#16 collision); handoff releases the claim via
`_release_pause_dispatch_owner(evse_id, "battery_drain")` only (`:1081`), no double-emit.

33/33 tests pass, including a mutation anchor proving the night-85 release regresses if
the gate is removed.

**Verdict: SHIP.** No must-fix. One LOW (documented `reserve_soc=None` strand) is
acceptable and in-contract.

## Verification checklist

### 1. `battery_out_of_capacity` reserve release UNCHANGED — PASS
`diff` of develop vs feature over the resume block shows the reserve clause is
identical (EV `energy_pool.py:1023-1033`; plug `:1928-1937`). Only additions are the
`elif`/comment context and the `solar_replenishing and` prefix on `soc_recovered`. The
reserve-gated guarantor is not weakened. **Not touched.**

### 2. `soc_recovered` solar-gate correctness — PASS
`soc_recovered = solar_replenishing AND soc is not None AND soc >= threshold+5`
(`:1029-1033`). Night/no-solar at 85 → `solar_replenishing=False` → no release; battery
drains to reserve → `battery_out_of_capacity` → grid charge. Daytime actively charging
at 85 → `solar_replenishing=True` (surplus>1.0 OR power>+100W) → releases, shares solar.
Covered by `test_night_high_soc_holds_no_solar_release`,
`test_day_high_soc_releases_with_solar`. Day case not broken
(`test_cloudy_daytime_pre_peak_still_holds` confirms fill-priority phase separation).

### 3. "Never discharge battery into EV" invariant across day/night — PASS
Pause condition unchanged: `state["charging"] AND battery_power_w<-100 AND soc<threshold`
(`energy_pool.py:992`). EV charge never pulls battery below reserve (reserve release is
the floor); high-SOC night battery no longer drained (the D2 fix). The genuine
daytime-no-solar discharge case still pauses. Confirmed `test_reserve_release_works_at_night`,
`test_mid_soc_no_release_either_phase`.

### 4. `expected_solar_surplus_now_pct` is the right TIME-anchored signal — PASS
Wraps `_expected_solar_surplus_pct(now, _minutes_to_high_rate_boundary(now))`
(`energy_battery.py:1648-1649`). Daylight-overlap pro-rated (`:1755`), ~0 at night.
Does **not** use raw `solcast_remaining` for the phase call — only as a kWh magnitude
inside a daylight-sliced fraction. The `1.0%` floor + `+100W` live OR-term is a
reasonable conservative constant (fails toward reserve-gated grid on any exception:
`energy.py:2701`, `energy_battery.py:1650`).

### 5. Restart / pause-ownership — PASS
`_paused_by_battery_drain` is the dedicated set (`energy_pool.py:199`), disjoint from
`_paused_by_fill_priority` (`:272`), grid_cap, arbitrage, load_shed. Resume handoff
releases only drain's claim (`_release_pause_dispatch_owner(evse_id, "battery_drain")`,
`:1070`/`:1081`); other owners retain dispatch tracking. No double-emit: terminal resume
discards membership once and releases once. New `solar_replenishing` is a per-tick
recomputed bool — no persisted state, restart-clean.
