## Findings

### LOW-1 — Icon semantics: `mdi:battery-arrow-down` on the Resume-EV slider

**File:** `number.py:928`
**Severity:** LOW (cosmetic)
**Description:** `ExcessSolarSOCNumber._attr_icon = "mdi:battery-arrow-down"` while `FillPrioritySOCNumber` uses `mdi:battery-arrow-up`. At first read this looks inverted (Resume = "up" intuition), but on second read it's defensible: at the moment the Resume-at-95 threshold engages, the home battery starts being **drained** to dump surplus into EVs — "arrow-down" tracks battery direction post-threshold, not slider semantics. FillPriority's "arrow-up" similarly tracks the battery filling toward 80.

**Risk:** Nil functional. User UX clarity is the only consideration.

**Recommendation:** Leave as-is. The icon consistency story (both icons track battery-power-direction at the moment the rule engages) is internally coherent. If user feedback post-deploy is that the icons are confusing, swap to `mdi:battery-charging-95` / `mdi:battery-charging-80` in a future LOW pass.
