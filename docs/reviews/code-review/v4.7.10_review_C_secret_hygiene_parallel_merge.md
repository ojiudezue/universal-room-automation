### Audit step 5 — Trap fires under every exit path

`scripts/dual-push.sh:54`:

```
trap restore_gitea_url EXIT INT TERM
```

| Exit path | Trap fires? | `.git/config` after exit |
|---|---|---|
| Success (rc=0) | EXIT | Clean URL (also written explicitly at L125) |
| Preflight failure (rc=1) | EXIT | Unmodified (preflight is before URL rewrite at L122) |
| Source / parse error (rc=2, `set -e` trip) | EXIT | If `set -e` trips AFTER L122 and BEFORE L125, EXIT trap restores clean URL via L51 set-url |
| SIGINT (rc=130) | INT → EXIT | Same protection as above — verified by test #8 |
| SIGTERM (rc=143) | TERM → EXIT | Same protection (test #8 logic is signal-agnostic) |
| SIGKILL (rc=137) | NO — kernel intercepts | Residual risk: credentialed URL may remain in `.git/config` until next push or manual reset. **Documented as known limitation** in README "Known Limitations" section, with operator remediation. ACCEPTED. |

PASS. All trappable exit paths restore clean URL. SIGKILL residual is documented + has a one-command operator fix.
