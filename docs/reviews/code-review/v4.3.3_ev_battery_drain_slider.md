| User drags to 5% (lower bound) | Always pause when discharging; aggressive policy |
| User drags to 95% (upper bound) | Almost always pause; user wants conservative policy |
| Decision tick after slider change | Reads `self._ev_battery_drain_soc` live; no caching regression |
