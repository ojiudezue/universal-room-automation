## Findings (all FIXED unless noted)

### HIGH

| ID | Bug class | Finding | Fix |
|---|---|---|---|
| A1 | Sentinel-undercount / silent failure | No per-evaluator try/except → one dimension raising killed all later dimensions AND the `cycle_ok` sentinel (the Review-D liveness signal). | Cycle iterates `(name, callable)` with per-iteration try/except + WARNING; sentinel always emits. |
| B1 | Untracked background task | Digest persist used bare `asyncio.create_task` (GC-able mid-flight, lost exceptions). | `hass.async_create_task(..., name=...)`. |
| B2 | Single-row-per-day fan-out | Multi-person digest fires wrote N duplicate rows/day → `get_recent_daily_digests` undersampled by person count. | `UNIQUE(date)` + `ON CONFLICT(date) DO UPDATE` upsert + in-memory `_last_persisted_digest_date` guard; new dedup test. |
| C1 | #44 test authority | `test_optimization_daily_digest_dao_roundtrip` hand-wrote the INSERT. | Rewritten to extract + drive the production `log_daily_digest` SQL against the real schema. |
| C2 | #44 test authority | `test_optimization_daily_digest_prune` hand-wrote the DELETE. | Rewritten to drive the real batched `prune_optimization_daily_digest` via an async bridge over the real-schema DB. |

### MEDIUM (all fixed)

- **A2** — `_notify_if_severe` dropped `dedup_key` → NM couldn't suppress a flapping high advisory (re-page every 5 min). Now forwards `event_class` + stringified dedup_key + a cross-cycle `_notify_dedup_state` TTL (12 cycles).
- **A3** — vacancy tz-normalization mislabeled a naive `continuous_occupied_since` as UTC (5-6h skew). Now promotes naive as local (`as_utc(as_local(...))`).
- **A4** — `_get_hvac_coordinator` legacy `hass.data` slot fallback won over the CM lookup (stale-path hazard, sibling of the Phase-1 A-CRIT-1 phantom slot). Now CM-first; legacy slot gated behind `_optimizer_test_mode`.
- **B3** — **the prune DAOs were never invoked** (Phase 1 `optimization_findings` AND Phase 3 digest → unbounded growth). Both wired into the existing `_cleanup_ops` daily cadence in `__init__.py`.
- **B4** — digest `date` field was UTC, not the local day-of-coverage. Now `dt_util.now().date()`; `generated_at` stays UTC for ordering.
- **C-sensor** — `_zone_scores` populated but surfaced on no sensor. Added `"zones"` to `OptimizerRoomHealthSensor.extra_state_attributes`.
- **C2-test** — room-health-attrs test reimplemented the derivation (#44). Rewritten to drive the real `RoomOptimizationHealthSensor`.
- **C3** — None-guard test extended to cover `generated_at=None`.

### LOW (fixed)
- **B5/B6** — DEBUG→WARNING on digest persist-schedule and section-render failures (a render bug shouldn't silently strip the section forever).
- **A6** — occupancy-accuracy now has a 120s sustained gate (motion-on/occupancy-off is transient at sensor wake).
- **A5** — deferred-dimension list logged once per startup, not per cycle.

### DEFERRED (accepted)
- **A7** — override-frequency high-severity at ≥20 can fire once near midnight before the counter resets; the threshold is high enough that any fire is informative. Documented.
- **LOW-1** — uniform 15-pt-per-finding scoreboard weighting is severity-agnostic (intentional simplification; single low-confidence advisory can't flip a room to critical). Noted in README.
