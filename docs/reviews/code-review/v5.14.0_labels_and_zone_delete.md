### Static-vs-behavioral anchor judgments recorded

- **Static-anchor accepted:** the six-table list in `database.py` is enumerated once and referenced by both the summarize helper and the DAO; a new zone-scoped table introduced later without touching this list would go unpurged. Reviewer A judged the static risk acceptable given the test now asserts the six-table shape by name.
- **Behavioral-anchor required:** the `SIGNAL_ZM_ZONES_UPDATED` dispatch is asserted *behaviorally* — a delete drives the dispatch, and the HVAC/presence handlers' effects are asserted on real coordinator instances, not on a signal-emit count.

### Plan deviation upheld

`fan_recheck_state` was listed in the original planning doc as a candidate table for purge. Build correctly **excluded** it after the `4fa6bd00` commit note flagged it as **per-ROOM PK, not per-zone** — including it would have corrupted surviving rooms' state on any zone delete. Reviewer A independently confirmed the PK shape and upheld the exclusion.

### Deferred (with mapping to live validation)

Four integration tests originally scoped in the plan (full delete → restart → verify no resurrection; delete → re-add same name → verify clean slate; delete with concurrent room reconfigure; delete during a live HVAC preset transition) were deferred to **Live Validation Criterion L1** on the live house rather than mocked at integration level — the mock harness cannot faithfully reproduce the ZM-reload-driven re-discovery. Live criterion covers all four scenarios as observable outcomes.

### Bug-class recommendations (to add to `docs/QUALITY_CONTEXT.md`)

1. **"Reads without writers"** — an options/data key still read by a listener after the last writer is removed silently re-pins stale values via `or`-fallback (A-HIGH-1). Related to #14 but the recurrence surface here is different (fallback across `data` vs `options`, not across defaults).
2. **"Hand-copied SQL/logic in tests"** — the initial `test_zone_delete_flow.py` mirrored the DAO's purge logic in-test rather than importing and driving it, which is why all five Review-C mutations went green pre-fix-up. Sibling of the v5.9.0 "stub-mirror" bug class.
3. **"Signal handler mutating a dict others iterate across awaits"** — P1's finding. Deletion cycles that add signal-driven mutation to a shared coordinator dict must audit all iteration sites of that dict for `await`-crossing loops.
