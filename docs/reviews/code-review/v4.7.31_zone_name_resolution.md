## New bug class proposed
**#53 — Name-vs-id collection lookup.** A `dict.get(<name>)` against a dict keyed by
a different identity (here zone_id) silently returns None forever; if the caller
treats None as "absent and skip," a whole feature can be dead with only a warning.
Guard: assert the key space of any `.get()` matches what the caller holds; tests must
mock the collection with the PRODUCTION key shape (the old tests mocked it name-keyed,
masking the bug — Bug Class #44 adjacency).
