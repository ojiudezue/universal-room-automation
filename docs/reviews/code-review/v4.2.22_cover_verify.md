## Findings Detail

### CRITICAL — fixed

**C1. `_cover_op_in_flight` flag never cleared on schedule failure.**
*Bug class:* concurrent reload race / leaked guard.
*Location:* `automation.py` four runner schedule sites.
*Issue:* if `hass.async_create_task` raised (loop closing, entry unloading), the in-flight flag stayed True forever, silently disabling all cover ops for that room until restart.
*Fix:* extracted `_schedule_cover_runner()` helper that wraps the schedule in try/except and resets the flag (and closes the coroutine) on failure.

### HIGH — fixed

**H1. Untracked background tasks.**
*Bug class:* untracked background tasks (recurring class).
*Issue:* `hass.async_create_task(_runner())` is fire-and-forget; the runner held a reference to `self` and continued mutating state after entry unload.
*Fix:* `_schedule_cover_runner` now uses `entry.async_create_background_task(hass, runner_coro, name)` (HA 2024.5+) so HA cancels the task on entry unload.

**H2. First-refresh skip not honored in independent cover branch.**
*Location:* `coordinator.py` new `else:` branch.
*Issue:* on first refresh after restart with master automation OFF, the new branch could fire blind commands before sensor state settled.
*Fix:* added `not self._skip_first_automation` guard to mirror the master `elif` branch behavior.

**H3. Position-based covers misclassified as stragglers.**
*Bug class:* incorrect state comparison for entities with attributes.
*Issue:* HA cover entities with `current_position` report `state="open"` for any position > 0. A blind closed to `position=10` was permanently re-commanded as a straggler.
*Fix:* new `_cover_at_target(state, target)` static helper uses `current_position` with 5%-tolerance window when available; falls back to `state.state` comparison.

### MEDIUM — fixed

**M1. Daily reset leaves stale failure metadata.**
*Fix:* `_maybe_reset_cover_counters` now also clears `_last_cover_failure_time` and `_last_cover_failure_entities`.

**M3. Total retry budget = 9 calls per cover (RF amplification risk).**
*Fix:* outer helper now passes `max_retries=0` to `_safe_service_call`; outer settle+verify is the single source of truth for retries. Worst case = 3 calls per cover (initial + 2 retries).

**M4. Sleep mode race in deferred runner.**
*Fix:* `check_timed_cover_open/close` runners re-check `is_sleep_mode_active()` inside the runner before issuing commands.

**M5. Activity log fires "Closed N covers" regardless of outcome.**
*Fix:* entry/exit runners now log actual outcome with success/failed counts and straggler list.

### MEDIUM — deferred

**M2. Date string TZ handling.**
Acknowledged. Consistent with existing `_last_timed_close_date` pattern in this file. Not changing in scope.

### LOW — partially addressed / deferred

**L1. Test coverage gaps.** Partially addressed: added 8 new tests covering position-based covers (5 cases incl. end-to-end), daily-reset metadata, and inner-retry assertion. Deferred: `_cover_op_in_flight` re-entrancy test, coordinator else-branch integration test (would require full HA test rig).

**L2. `_send_covers_with_verify` does not refresh `_refresh_config()`.** Deferred — single batch is short-lived; stale `available` list is acceptable.

**L3. `pending[-1]` skip-trailing-pause logic.** Verified correct, no fix needed.
