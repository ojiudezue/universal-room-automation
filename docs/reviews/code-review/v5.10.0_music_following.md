## Bug-class frequency

- **Cross-coordinator read without a verified writer** — 3 (C-CRIT-1 seed key, A-CRIT-1 substrate key, A-CRIT-2 dwell key). This is the headline pattern of the cycle: **mechanism built, wire missing.** Three separate CRITICALs were gates or gadgets reading a data source that had NO writer on the producing side. In each case a test injecting the never-written key masked the defect and let the CI stay green.
- **Dead code / dual authority** — 2 (B-HIGH-1 sync_enabled_persons, B-HIGH-2 _enabled_persons dual owner).

## QUALITY_CONTEXT.md recommendation

Propose a new bug class:

> **"Cross-coordinator read without a verified writer."** When code reads from `hass.data`, a coordinator's `.data` dict, or any shared registry, the READER must cite the writer's `file:line`. If no writer exists in the current tree, the read is a permanent no-op. Corollary (test-authority): a test that INJECTS the key the production code never writes proves nothing about the production path — the mutation of removing the writer must fail a named test.

This is the single-line summary of the v5.10.0 CRITICAL pattern. It generalizes (Bug Class #53 "computed-but-not-consumed" is the write-side dual; this is the read-side dual). Two of the three CRITICALs in this cycle would have been caught by a linting rule that fails when a reader can't cite a writer.

**Sub-recommendation:** tighten the strings/translations parity test to compare label VALUES for a fixed reference locale (en), not just structural key parity — C-L2 was quietly masked for the whole build.

## Invariant

**Test anchor:** `quality/tests/test_v5100_music_following.py::test_sleep_gate_seeded_from_house_state_on_setup` — this test restarts the coordinator with the HouseStateMachine already in `SLEEP`, delivers a `RoomTransition` immediately, and asserts (a) zero `media_player.*` service calls, (b) `sleep_suppressed` stat incremented, (c) `_current_house_state == HouseState.SLEEP`. Removing the seed path (mutating the seed to `pass`) fails this test — verified in fix-up FIX-2 red/green.
