## Cleared (holds because)

- **Store load before recheck:** `_load_away_store` runs in `async_setup` (:513-516) before `_call_later(...boot_recheck)` (:578). The setup `_save_store` (:544) writes the loaded mark back unchanged. The load is wrapped in try/except, and the mark defaults to None (`__init__` :198), so missing or corrupt data reads as no mark (fail secure). Validation at :2226-2232.
- **Lost delayed save:** `async_delay_save(…, 1.0)` (:2202) is flushed by the HA Store final-write listener on clean stop. A reload flushes synchronously in teardown (:704-709). Only a hard crash within 1 s loses the mark, and that fails secure (one re-lock). Matches the README.
- **Own release vs manual detection:** `_spawn_unlock` adds to `_release_inflight` synchronously after `async_create_task` (:1474-1480), before the task runs, so the state event from our own unlock always sees the entity in flight. SC-disable sets `_disable_releasing` across the awaited loop with try/finally (:740-744).
- **Exit edges:** wake / `home_*` / `arriving` / backstop / boot-recheck release all route `_release` → `_after_release` → `_clear_manual_unlock` (:1418-1428). SC-disable clears (:746). A live engage edge clears (:812). The recheck clears on an awake house or a different episode (:885-893). Gap: B-2.
- **Ordering:** `_record` runs before `act()`. The recheck runs under try/except so the away-lock rearm still runs (:634-640). The timer unsub is nulled first and torn-down is guarded (:622-624). Teardown cancels `_boot_recheck_unsub` (:663).
- **Guest yield INV-LOCK-1:** `boot_unknown` in `home_night` inside the window with the toggle on maps to `guest_night`, then `guest_yield_hold`, and the mark is not cleared (`ended` excludes `guest_yield_hold`, :886-888). A partially unlocked pair stays held. A guest_night mark plus a yielded, fully unlocked pair gives reason NONE and decision `none`, which clears the mark harmlessly because no engage is possible.
- **Flapping (false wake sleep→waking→sleep):** waking releases and clears, then sleep starts a new episode and re-locks. The semantics are correct.
- **Vacation at any hour:** an engage goes through `_request_engage`, so the observation-mode, predicate and excluded gates still apply (:1589-1614).
