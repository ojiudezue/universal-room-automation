## Safety highlights (from reviews)
- Prune is **boot-safe by construction**: even if circuit discovery is empty, only
  "Unmapped Tab%" scopes are deleted; real-name baselines are kept/warned.
- Prune is **scoped** to `coordinator_id='energy' AND metric_name='circuit_power'` —
  never touches peak_import/soc/cost/solar baselines, safety_rate, diagnostics, or
  Emporia/nested circuits (real circuits never named "Unmapped Tab N" per SPAN
  Circuit Name Sync).
- Prune is **transactional** (single commit; partial failure rolls back cleanly) and
  **idempotent** (no-op once pruned).
- heat_cool re-assert is **capability-guarded** — heat-only/cool-only units keep
  their mode; all live zones run heat_cool.
- No callers of `_revert_override`/`_restore_after_reset` rely on restoring the
  pre-reset single mode; egress restore is a separate path (no collision). No tests
  asserted the old behavior.
