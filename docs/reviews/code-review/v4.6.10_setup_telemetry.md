- Planning: `ura-planner` (delivered inline due to missing Write tool — filed for v4.6.11 cleanup to add Write to ura-planner agent frontmatter)
- Build: `ura-builder` (now claude-opus-4-7)

**Outcome:** Two reviewers convergently flagged the same CRITICAL via different framings. That's the Tier 2 ceremony working as designed. A single-reviewer Tier 1 might have caught one angle (e.g., missing `store_event`) without the second angle (ephemeral baseline) — leading to a hotfix v4.6.10.1 that adds `store_event` but still doesn't work because the baseline never matures.

2. `ura-validator` baseline-diff methodology has artifact (new test files execute against baseline prod) — directional result correct, absolute counts slightly inflated
