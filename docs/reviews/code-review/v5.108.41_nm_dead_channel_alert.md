# Review record: NM dead message-channel alert (NM-IMESSAGE-OUTBOUND-DEAD-1)

Version: planned 5.108.41 (rename at deploy if another release ships first).
Tier: 2. Plan: `docs/planning/PLANNING_nm_dead_channel_alert.md`.
Branch: `feature/nm-dead-channel-alert`. Build `5f5d1dc0b` (tag `pre-review-nm-dead-channel`), fix-up `83b1e70a7`.

## Why
iMessage sends failed 100% from 2026-11-22 17:12 to 2026-11-27 02:43 (a Cloudflare HTTPS 301 on the
BlueBubbles host turned each POST into a body-less GET). Nobody was told for 4.5 days: other channels
delivered, and notification_log marks multi-channel rows delivered=1. This cycle adds an operator alert
when one message channel (pushover, companion, whatsapp, imessage) fails every send for 6 h or more.
