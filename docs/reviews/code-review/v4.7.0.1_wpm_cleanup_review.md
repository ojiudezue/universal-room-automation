**File:** `weather_manager.py:262`
**Finding:** Signature is `priority_rank_for(self, entity_id: str) -> int | None` but the caller in `sensor.py:6392` guards with `if active is not None else None`, implying `entity_id` can be `None`. **Action:** No fix required for this hotfix. If the method's signature is ever updated, consider `entity_id: str | None`.
**Bug class:** None (cosmetic type hygiene).
