## Is the cycle worth it as scoped?

- **Lint:** this is the real value, the structural guard against a "7th site" that INV-G needs, and it sets up `EC-INCLEMENT-HARDENING-1`'s D-blind routing. It is worth it **only after R2-05**. As specified, it misses the action-dict shape that every real reserve writer except one uses.
- **History:** worth it, but as written it is desire history mislabelled as write history (R2-01). The essential missing piece is a row at the dispatch tap. Without it, the "governed slice with history" is not truthful under EVSE overlay or deadband.
- **Restart resilience:** honestly nothing new is needed, since `wv_commanded_ledger` already covers it and the DB rows are durable. Fine.
- **"Registry of one floor":** this is one 5-line accessor. It is fine, and not a registry; don't let the builder build a table.
- **Excess to cut:** `_tick_id` (R2-02), the second lint assertion (R2-09), and possibly the 20-row history attr (keep only `last_reserve_write`; history lives in the DB).
