## Cleared

- **Sleep-onset mid-pause collision**: `_sleep_onset_activation` (hvac_fans.py:986+) does not check `fan_recheck_suppress_until`. It cannot reach a paused bedroom, though. SLEEP is entered only from HOME_NIGHT (`house_state.py:96-97`), and a bedroom cannot be PAUSED in HOME_NIGHT (it is refused at eligibility and arm expiry). The only exception is B-1, which ends within about 3 minutes. No path from B-1 then crosses into sleep while still paused within the window.
- **Restart / rehydrate a PAUSED bedroom** (`_restore_row:1741-1757`): a fresh row restores OCCUPIED_CONFIRMED, meaning the fan comes back ON, regardless of house state. That fits the night keep-on contract. A stale row goes to IDLE. ARMED and RESTORING rows go to IDLE. Room type has no bearing here.
- **v4.7.13 HOLD vs pause**: while paused, the HVAC per-room loop skips the room (`hvac_fans.py:654-663`). That covers the ISO window, which spans spindown + window + margin (`:819-824`), so the pause and the HOLD do not fight.
- **`_l1_persons`**: reads `person_coordinator._area_id_to_room` (person_coordinator.py:118, 992-994; keys are area_id, name, and the normalized name). It only reads that map. The `seen` set prevents counting the same room twice, and there is no added async. The inert sink stays pure because `_l1_persons` mutates nothing.
- **Media room at night**: this change tightens behavior. A media room on the Tier-1 L3 path could arm through sleep before; now it is refused. Covered by `test_sleep_begins_during_arm_delay_aborts_before_pause_media_room`.
